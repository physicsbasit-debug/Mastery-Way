# بوصلة الإتقان

تطبيق ويب لتحليل نتائج الطلبة وإنتاج قراءات تربوية وتقارير رسمية قابلة للطباعة، بهدف دعم قرارات المعلم والمدرسة بناءً على مؤشرات واضحة بدل الاجتهادات المتناثرة.

## المسارات المعتمدة

1. **تحليل انتشار الإتقان**
   - تحليل جماعي للدرجات النهائية.
   - يحسب نسبة انتشار الإتقان ويقدم الحكم العام والفجوة والخطة الجماعية.

2. **تحليل الأداء الفردي**
   - تحليل طالب واحد في ورقة محددة.
   - يربط المفردات بالمهارات وأنماط الخطأ.
   - ينتج تقريرًا تفصيليًا وخطة متابعة موجهة للطالب وولي الأمر والمعلم.

3. **تحليل مفردات الورقة الامتحانية من عينة**
   - تحليل عينة من أوراق الطلبة.
   - يقرأ أداء المفردات والمهارات وتوازن الورقة.
   - ينتج تقريرًا تفصيليًا توثيقيًا قابلًا للطباعة.

## ملاحظات تشغيل

- يعتمد التطبيق على Vite + React + TypeScript.
- `app.tsx` يعمل كغلاف رئيسي يربط المسارات الثلاثة المعتمدة.
- لا تعتمد البنية الحالية على مجلدات الجسور القديمة.
- التقارير تطبع محتوى التقرير فقط ولا تطبع واجهة التطبيق كاملة.
- مجلد `comparison/` يحتوي مكونات مقارنة تحليلية محفوظة داخل المشروع، ولا يظهر كمسار مستقل في الصفحة الرئيسية حاليًا.

## استخدام المشروع كقالب GitHub

هذه النسخة مجهزة للعمل كـ **Template repository** دون Git LFS. يتعرف Vite تلقائيًا على اسم المستودع أثناء GitHub Actions، لذلك لا يلزم تعديل `base` لكل مشروع جديد. راجع `TEMPLATE_SETUP.md` للخطوات المختصرة.
